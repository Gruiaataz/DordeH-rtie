# Dor de Hârtie — site de felicitări digitale

Un site static responsive în limba română, cu stil editorial inspirat de hârtie, motive florale și culori calde.

## Fișiere
- `index.html` — paginile/secțiunile și conținutul
- `style.css` — design responsive, animații și efecte la scroll
- `script.js` — meniul mobil, filtrarea colecției, preview modal și formularul care pregătește un email

## Cum îl deschizi
Deschide `index.html` într-un browser. Pentru publicare, încarcă toate cele trei fișiere pe un hosting static (de exemplu GitHub Pages, Netlify sau un hosting web obișnuit).
